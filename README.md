Sistema bancário com Python
Projeto de estudo para o desafio Criando um Sistema Bancário com Python, do bootcamp Vivo — Python AI Backend Developer da DIO.
Executar
Requer Python 3. Execute no terminal:
```bash
python sistema_bancario.py
```
Funcionalidades
Depósitos positivos.
Saques com saldo suficiente, até R$ 500 por operação e até 3 operações por execução.
Extrato de operações aprovadas e saldo com duas casas decimais.
Validação de números, inclusive entrada com vírgula decimal.
Uso de Decimal para evitar imprecisões de ponto flutuante nos valores.
Os dados ficam em memória e são apagados ao encerrar. O limite de saques reinicia a cada execução; esta versão didática não controla dias, usuários ou contas reais.
Exemplo
Deposite 1000, saque 200 e consulte o extrato: o saldo será R$ 800.00.
Conceitos praticados
Variáveis, condicionais, laço while, entrada e saída, listas, strings, funções e tratamento de erros.
